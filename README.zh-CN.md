# Gravity WorldTime

**放在 Windows 桌面上的世界时间尺与时间圆环，支持离线城市搜索。**

让朋友和联系人出现在各自当地的时刻，用直条或 24 小时圆环看懂彼此处于一天中的哪个阶段。日期、头像和作息插画随人物显示。**0.3.3** 将离线地点库扩展至 **69,970 个聚居地点**，加入多语言搜索。

## 用两种形态看懂一天

- **直条时间尺：**人物沿当地小时排列，分别标注日期；靠近的人物可以聚合显示。
- **圆环时间钟：**同一批人物和时区规则围绕 24 小时圆环排列。右键“显示模式”切换，两种模式分别记住位置和大小。
- **可调圆环：**拖动缩放箭头/握柄或使用大小菜单。“我”与附近联系人保持可区分。
- **桌面驻留与置顶：**驻留 Explorer 桌面，或固定在普通窗口上方；托盘提供管理与恢复入口。
- **个人作息与头像：**设置头像、显示名称、独立作息，支持 12/24 小时制。界面有英语、简体中文、繁体中文和日语。
- **轻微动态或安静静态：**星光、日月光晕、云朵和作息小动作；可选动态、低动态、完全静态，并可跟随 Windows 动效偏好。

直条和圆环表达的是每日时钟循环，不是一条统一的全球日期时间线。天空只是通用氛围，不是实时天气；人物状态来自作息推测，不代表对方真实活动或是否方便联系。

## 用熟悉的名称找城市

随包 GeoNames 子集包含 69,970 个地点、245 个国家/地区代码。可搜索城市名、部分名称、已有别名、无声调拼音、首字母，以及数据库收录的其他文字名称。搜索语言不受四种界面语言限制，但不代表所有地名都有完整翻译。

例如：**旧金山、San Francisco、jiujinshan、Tokyo、东京、São Paulo、Sao Paulo**。用国家筛选缩小范围；候选显示国家、行政区与 IANA 时区，添加前选择正确地点。同名城市可能有多个，不能只看名称就认定时区。

*最终 0.3.3 构建的真实窗口，使用独立合成配置。蓝色指针光晕来自截图/操作工具，不代表已选中城市。*

![拼音搜索](media/city-0.3.3/033-pinyin-jiujinshan.jpg)

*真实 0.3.3 搜索组件画面；构建归属见[素材说明](media/city-0.3.3/PROVENANCE.md)。*

搜索使用内置数据和 Windows 时区规则，不依赖收费 AI 或联网地理编码。保存稳定地点 ID、IANA 身份与 Windows 映射，夏令时采用本机规则，不以固定 UTC 偏移代替。数据和系统映射可能缺失或过时，仍保留手动城市/时区入口。旧联系人不会为匹配新城市库而被静默删除或改名。

**0.3.3 不能解析任意完整地址。**请用“旧金山”等城市名配合国家筛选。连续输入“美国加利福尼亚州旧金山”不属于本原版支持范围；后续 0.3.3.1 的自然地址修复不在本包中。

## 下载与启动

1. 从 [0.3.3 发布页](https://github.com/wbyhome/Gravity-WorldTime/releases/tag/v0.3.3)下载 **Gravity-WorldTime-v0.3.3-win-x64.zip**。
2. 完整解压到一个**新的可写文件夹**，保留许可和说明文件。
3. 如有需要，安装 **.NET 8 Desktop Runtime x64，包含 WPF**。目标为有交互式 Explorer 桌面的 Windows 10/11 x64，并非所有 Windows 配置均已认证。
4. 双击 **Start-WorldTime-Ruler.cmd**。它传入 `--ruler-desktop`，使用程序旁独立的 `ruler-preview-data`。
5. 右键“添加联系人”，搜索城市、选择正确候选、填写显示名称后添加；从“显示模式”切换直条与圆环。
6. 备份或更新前，先从时间尺/托盘菜单正常退出。

不带启动器参数直接运行 EXE 仍进入旧式模式。这是依赖运行时的便携预览，**不是安装器或 Store 包**，不会更新已安装的新版 WorldTime。下载不含个人配置或 PDB；ZIP 可用 `SHA256SUMS.txt` 核对。

## 日常操作

| 操作 | 0.3.3 中的入口 |
|---|---|
| 移动直条 | 拖动左侧内嵌握柄 |
| 切换形态 | 右键 → 显示模式 |
| 调整直条/圆环大小 | 缩放控制点或大小菜单 |
| 添加、编辑联系人 | 时间尺右键、人物详情或托盘管理 |
| 设置头像和独立作息 | 人物编辑操作 |
| 修改“我”的名称 | 更多设置 → 我的显示名称 |
| 调整透明度 | 右键 → 调整透明度 |
| 动画 | 更多设置 → 动画效果 |
| 悬浮在普通窗口上方 | 固定最上层；取消后返回桌面 |
| 找回屏幕外界面 | 重置位置或托盘恢复 |

全区域拖动和简化联系人添加流程属于 0.3.3.1。关于/版本窗口、更大的头像、明确的双人时差比较属于后续版本，不是本版功能。核对本原版身份时，可看 `Gravity.WorldTime.dll` 文件属性中的详细信息：文件版本 **0.3.3.0**。

## 配置与更新

本预览使用 `ruler-preview-data`，与旧式 `data` 及新版安装应用的用户数据分开。先退出旧程序并完整备份；解压到新目录，不自动迁移。确需转移时，双方退出后复制兼容的**完整、带标记的时间尺配置目录**。不要覆盖已安装的新版，也不要把新版数据倒灌进本历史预览。导入头像副本位于配置目录，不能将该目录公开上传。

添加/删除联系人不会整理或删除桌面文件。旧式管理界面保留可选的 Windows 系统时区修改，查看世界时钟不需要它；修改时区不等于网络 UTC 校准，0.3.3 不含后续校准服务。

## 验证与已知限制

使用原审核 0.3.3 DLL/EXE，发布时不重新构建。编译输入覆盖 **74 个 C# 文档与三个嵌入资源**。原记录通过：78 项城市/搜索、544 项模型/城市库、1415 项程序化 WPF、455 项圆环/操作检查。用户确认中文输入法提交不会误添加；后续在原 0.3.3 原生启动路径复查也能找到“旧金山”。这些不等于所有桌面环境或输入法认证。

- 测试机首次城市索引约两秒。本版关闭搜索后缓存仍保留，内存占用可能明显，未包含后续优化。
- 多语言别名、首字母和拼音受源数据覆盖限制，不是通用翻译或错字纠正。
- 物理断网、日文输入法、低配置机器、长时间运行、Explorer 重启、混合 DPI/多屏变更及休眠恢复仍未完成全面验收。
- 原交付未重做 0.3.3 全套 Win+D/置顶/透明穿透人工矩阵；不拿前后版本确认冒充本版验收。
